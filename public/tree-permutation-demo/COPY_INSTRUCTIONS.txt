Tree Permutation Demo のコピー手順
====================================

コピー元（Windows）:
  C:\Users\PC_User\Documents\01.Math\09.MathAlps\GeometlizationOfPermutation\PROGRAM\my-tree-permutation-demo

コピー先（このプロジェクト）:
  public/tree-permutation-demo/

--- WSL / Linux で実行する場合 ---

my-tree-permutation-demo の中身（index.html および js, css 等）をこのフォルダにコピーしてください。

例（WSL で Windows のパスにアクセスする場合）:
  cp -r /mnt/c/Users/PC_User/Documents/01.Math/09.MathAlps/GeometlizationOfPermutation/PROGRAM/my-tree-permutation-demo/* /home/shiratama/my-projects/shiratama-dashboard/public/tree-permutation-demo/

例（既に shiratama-dashboard 内にデモを置いている場合）:
  cp -r /path/to/my-tree-permutation-demo/* /home/shiratama/my-projects/shiratama-dashboard/public/tree-permutation-demo/

--- Windows のコマンドプロンプト / PowerShell で実行する場合 ---

  xcopy "C:\Users\PC_User\Documents\01.Math\09.MathAlps\GeometlizationOfPermutation\PROGRAM\my-tree-permutation-demo\*" "C:\...\shiratama-dashboard\public\tree-permutation-demo\" /E /I /Y

（"C:\..." は shiratama-dashboard の実際のパスに置き換えてください。）

--- エクスプローラーで手動コピーする場合 ---

  1. my-tree-permutation-demo フォルダ内の「中身」すべて（index.html や js, css フォルダなど）を選択してコピー
  2. この public/tree-permutation-demo/ フォルダに貼り付け（既存の COPY_INSTRUCTIONS.txt と index.html は上書きまたは残してよい）

コピー後、ダッシュボードの「Tree Permutation Demo」リンクからデモが表示されます。
